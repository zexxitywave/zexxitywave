<h3 align="center">⚖️ <a href="https://github.com/zexxitywave/Flow-balancer">Flow-Balancer</a></h3>
<p align="center">
  <img src="https://img.shields.io/badge/Pure_Java-A855F7?style=flat-square" />
  <img src="https://img.shields.io/badge/WRR_+_Least--Conn-0EA5E9?style=flat-square" />
  <img src="https://img.shields.io/badge/Multithreaded-22C55E?style=flat-square" />
</p>

Application-level TCP load balancer built from scratch in pure Java — no frameworks. Socket-level request forwarding across 5 workers, each backed by a thread-safe PostgreSQL connection pool with stale-connection recovery.

**✦ Architecture**
- Weighted Round-Robin and Least-Connections scheduling
- Per-worker thread-safe connection pool with auto-reconnect
- Automatic health checks — dead workers marked DOWN and restarted
- Graceful shutdown — drains in-flight requests before JVM exit
- Live terminal dashboard — status · active load · avg latency · uptime
- Built-in load test client — P50/P90/P95/P99 reporting
- All DB queries via `PreparedStatement` — SQL injection safe

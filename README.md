### 🛒 [EventDrivenMesh](https://github.com/zexxitywave/EventDrivenMesh)
**Event-Driven E-Commerce · 16 Microservices · Kafka Saga**

Production-grade e-commerce backend on Spring Boot 3 + Java 21. Built around a choreography-based Kafka saga with automatic compensating transactions across inventory, payment, and shipping. A central API Gateway handles JWT validation and load-balanced routing via Eureka.

**Highlights**
- Transactional Outbox pattern — guaranteed at-least-once Kafka delivery
- Polyglot persistence — PostgreSQL, MongoDB, Redis owned per service
- Gateway-level JWT auth — validated once, trusted headers downstream
- pgvector HNSW semantic search — 768-dim Ollama embeddings
- CQRS analytics — dedicated read DB, batch Kafka consumer + DLQ
- Kubernetes HPA — CPU/memory autoscaling, zero-downtime rollouts
- PDF invoice auto-generated, emailed, and stored on every order
- Prometheus + Grafana — HTTP latency p95/p99, Kafka lag, JVM heap

### ⚡ [EnerFlux](https://github.com/zexxitywave/EnerFlux)
**IoT Energy Monitoring · 3-Stage Kafka Pipeline · Real-Time Alerts**

Production-grade IoT monitoring system on Spring Boot 4 + Java 21. A 3-stage Kafka pipeline ingests device energy readings, persists to InfluxDB time-series, classifies WARNING/CRITICAL thresholds via rolling aggregations, and delivers async email alerts with billing projections.

**Highlights**
- Manual Kafka ack after InfluxDB write — zero data loss guarantee
- 1-hour rolling aggregation with per-user threshold classification
- Round-robin partitioning across 5 consumers for full parallelism
- Async SMTP email — Kafka consumer threads never blocked
- AWS S3 parallel complaint uploads via `CompletableFuture`
- Circuit breaker at API Gateway via Resilience4j
- Keycloak OAuth2 / JWT authentication
- 4 Grafana dashboards · 19 Prometheus alert rules

### 🤖 [invoice-processing](https://github.com/zexxitywave/invoice-processing)
**Serverless AI Invoice Automation · AWS Lambda + Textract + Bedrock**

Fully serverless invoice pipeline on AWS ap-south-1. Vendors email PDFs → SES ingests → Textract extracts with per-field confidence scoring → Bedrock Nova-Lite validates and risk-scores → deterministic rules auto-approve or route to human review.

**Highlights**
- 10 Lambda functions — extraction, review, token approval, digest, cleanup
- Idempotent extraction — deduped on `invoiceId`/`objectKey`
- Human-in-the-loop — React 19 dashboard + 72-hour signed email tokens
- Daily digest + 72-hour escalation via EventBridge scheduled triggers
- Warm-up Lambda keeps 4 interactive functions hot every 5 minutes
- React 19 SPA on AWS Amplify — auto-deploys on push to main
- Full audit trail with filters and CSV export

### ⚖️ [Flow-Balancer](https://github.com/zexxitywave/Flow-balancer)
**Multithreaded TCP Load Balancer · Pure Java · WRR + Least-Connections**

Application-level TCP load balancer built from scratch in pure Java — no frameworks. Full socket-level request forwarding across 5 worker processes, each backed by a thread-safe PostgreSQL connection pool.

**Highlights**
- Weighted Round-Robin and Least-Connections scheduling algorithms
- Per-worker thread-safe connection pool — stale connections auto-reconnected
- Automatic health checks — dead workers marked DOWN and auto-restarted
- Graceful shutdown — drains in-flight requests before JVM exit
- Live terminal dashboard — status, active load, avg latency, uptime per worker
- Built-in load test client — P50/P90/P95/P99 latency reporting
- All DB queries via `PreparedStatement` — SQL injection safe by design
